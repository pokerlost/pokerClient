# Flutter toolchain

Use Flutter 3.47.0, commit `4cf24164269a5ebf0c16a028a00727d0e77bbb05`, with bundled Dart 3.13.0. Resolve the native pub workspace once at the repository root and commit its lockfile. Analytics configuration and download caches belong in task-specific writable directories.

Android/iOS/Linux/macOS adapters are generated by this exact SDK. Apple builds need an approved macOS runner. Android licenses are an owner action; unsigned debug output does not permit store delivery. Debug/release signing is disabled here, and no key is generated. Linux system dependencies can be provided by a disposable build image; the Debian-only installer remains independent.

The SDK bootstrap fetches the exact release tag and verifies its full commit. A detached shallow SHA without the tag can be reported as `0.0.0-unknown`, which correctly fails workspace constraints. `make docker-artifacts` separates SDK/pub, native/web builds and artifact export; `make docker-native-test` runs fresh integration acceptance with Xvfb. GTK/clang live inside the build image, not the workstation installer.

The source and native jobs test the exact PR head. Private `ghcr.io/pokerlost/poker-game-web` publication requires this same repository, passing jobs and an administrator-set `CLIENT_ARTIFACT_REVIEWED_SHA` equal to that full head. It publishes only a development OCI asset image, records the digest and asserts private visibility; it never creates a release or deploys. Each new head needs a new explicit review. The package inherits pokerClient access through its source label; pokerWeb CI additionally needs read access in the package's Manage Actions access settings. No SDK App installation is broadened for artifact exchange.
