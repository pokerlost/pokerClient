# Flutter toolchain

Use Flutter 3.47.0, commit `4cf24164269a5ebf0c16a028a00727d0e77bbb05`, with bundled Dart 3.13.0. Resolve the native pub workspace once at the repository root and commit its lockfile. Analytics configuration and download caches belong in task-specific writable directories.

Android/iOS/Linux/macOS adapters are generated by this exact SDK. Apple builds need an approved macOS runner. Android licenses are an owner action; unsigned debug output does not permit store delivery. Debug/release signing is disabled here, and no key is generated. Linux system dependencies can be provided by a disposable build image; the Debian-only installer remains independent.
